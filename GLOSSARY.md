# Глоссарий tessera

Канонические понятия домена инженерного фреймворка tessera, расклассифицированные по видам ДДД
из [правил DDD](./plugins/tessera-plugin/rules/ddd.md): ограниченный контекст, роль, сущность,
объект-значение, доменная служба, внешний справочник. Определение понятия живёт только здесь;
остальные артефакты понятие потребляют, не переопределяя.

## Контекст

**Инженерный фреймворк tessera (Tessera Engineering Framework)** — ограниченный контекст:
Минимальный набор правил работы с репозиториями, процессами и построения ПО и навыков,
их применяющих; гибкий пересмотр sdd-developer-kit без привязки к харнесу.
_Avoid_: поставка tessera, набор, тулкит, методология

## Роли

**Потребитель (Consumer)** — роль:
Получатель поставки — человек или команда, применяющие навыки и правила tessera в своём
харнесе.
_Avoid_: клиент, пользователь

## Сущности

**Плагин (Plugin)** — сущность, агрегат:
Устанавливаемая единица-адаптер для харнесов с маркетплейсами: зеркальные манифесты поверх
навыков и правил; корень агрегата — манифест.
_Avoid_: расширение, пакет

**Маркетплейс (Marketplace)** — сущность, агрегат:
Каталог установочных записей, из которого харнес ставит плагины; в tessera — `tessera`,
владелец `usp`.
_Avoid_: рынок, стор

**Навык (Skill)** — сущность агрегата «Плагин»:
Каталог `skills/<имя>/SKILL.md` — единица способности, исполняемая харнесом.
_Avoid_: скилл, команда

**Правила (Rules)** — сущность агрегата «Плагин»:
Нормы оформления и процесса из `rules/`, обязательные к чтению агентами по `AGENTS.md`.
_Avoid_: конвенции, инструкции

**Запись (Marketplace Entry)** — сущность агрегата «Маркетплейс»:
Строка маркетплейса: имя плагина, источник и версия.
_Avoid_: позиция, элемент

**Хранилище (Storage)** — сущность:
Локальные клоны источников в `~/.local/share/tessera/`, на которые ссылаются регистрации
навыков; повторный запуск поставки доводит их до ветки `main`.
_Avoid_: кеш, репозиторий

**Секция правил (Rules Section)** — сущность:
Управляемая часть `AGENTS.md` проекта между маркерами `delivery-tessera-<штамп>`: поставщик,
время подключения и перечень подключённых правил ссылками на их копии в `.tessera/rules/`.
_Avoid_: блок, вставка, анкета

**Лаунчер (Launcher)** — сущность:
Обёртка CLI зависимости на PATH: задаёт `BACKLOG_HOME` и передаёт вызов поставке backlog
в хранилище.
_Avoid_: shim, враппер, алиас

## Объекты-значения

**Идентификатор плагина (Plugin ID)** — объект-значение:
Ссылка на плагин вида `имя@маркетплейс` — способ адресации плагина между маркетплейсом
и харнесом.
_Avoid_: полное имя

**Зависимость (Dependency)** — объект-значение агрегата «Плагин»:
Чужой плагин, необходимый навыку; ставится скриптом поставки по профилю и проверяется
при запуске навыка.
_Avoid_: библиотека, требование

**Профиль поставки (Delivery Profile)** — объект-значение:
Состав доставки скриптом установки: только tessera, tessera с backlog, полный —
с mattpocock-skills.
_Avoid_: конфигурация, вариант, режим

## Доменные службы

**Поставка (Delivery)** — доменная служба:
Доставка фреймворка потребителю скриптом установки: раскладывает источники в хранилище,
регистрирует навыки в каталогах харнесов, подключает правила к проекту и ставит лаунчер CLI
зависимостей.
_Avoid_: релиз, дистрибутив

**Установка (Installation)** — доменная служба:
Доставка фреймворка потребителю плагином из маркетплейса — альтернатива поставке
ради обновления кнопкой.
_Avoid_: поставка, регистрация, подключение правил

**Регистрация (Registration)** — доменная служба:
Связывание навыков с каталогом навыков харнеса симлинками — механизм скрипта поставки
и локальной настройки разработчика.
_Avoid_: подключение правил

**Подключение правил (Rules Connection)** — доменная служба:
Ведение правил проекта скриптом поставки с `--project`: копии правил в `.tessera/rules/`
и секция правил в `AGENTS.md`; повторный запуск обновляет их, `--uninstall --project` снимает.
_Avoid_: копирование, импорт, инъекция

## Внешние справочники

**Харнес (Harness)** — внешний справочник:
Агентская среда, исполняющая навыки и устанавливающая плагины; поставка адаптируется
к харнесу, а не наоборот.
_Avoid_: среда, IDE, агент
