## Зависимости

Навык `workflow-fast` требует навыки `backlog-generate` и `backlog-run` плагина backlog;
`workflow-grill` — дополнительно навык `grilling` плагина mattpocock-skills. Зависимости —
опциональная поставка: их ставит скрипт поставки `scripts/install.sh` по профилю — `backlog`
для `workflow-fast`, полный для `workflow-grill`; профиль «только tessera» обходится без них.
Навык проверяет зависимость первым шагом, и её отсутствие останавливает его отказом с одной
командой запуска скрипта.

## Подключение

Поставка — скрипт `scripts/install.sh`: одной командой без клона либо запуском из клона.
Он раскладывает источники в хранилище, связывает навыки симлинками с каталогами навыков
найденных харнесов и ставит лаунчер `backlog`; ставится для всех проектов либо параметром
`--project` в текущий проект. Состав параметров печатает `scripts/install.sh --help`, шаги
установки — корневой `README.md` репозитория tessera.
