## Правила

Точка входа к правилам фреймворка: назовите код (`DOC-014`, `READ-004`) или тему — навык
называет правило и путь, применяет его к задаче.

| Тема | Правило |
|------|---------|
| Документы и их оформление | [`documentation-rules.md`](../../rules/documentation-rules.md) |
| Чтение документов, границы контекста задачи | [`reading-rules.md`](../../rules/reading-rules.md) |
| Окружение: mise, сервисы, переменные | [`environment.md`](../../rules/environment.md) |
| Архитектура слоёв, SOLID, модули | [`clean-architecture.md`](../../rules/clean-architecture.md) |
| Контракты чтения и записи | [`cqrs.md`](../../rules/cqrs.md) |
| Домен: контексты, агрегаты, события | [`ddd.md`](../../rules/ddd.md) |
| Документы для людей: README, CONTRIBUTING, кейсы | [`project-docs-rules.md`](../../rules/project-docs-rules.md) |
| Ветки, коммиты, границы git | [`git-rules.md`](../../rules/git-rules.md) |

Профильные навыки ссылаются на свои правила сами; хуков и автозагрузки нет — универсальность
важнее автозагрузки.

## Зависимости

Навык `workflow-fast` требует навыки плагина backlog; `workflow-grill` — дополнительно навык
`grilling` плагина mattpocock-skills. Нативной авто-установки зависимостей в формате плагинов
нет: зависимости ставятся из того же маркетплейса `tessera` (записи `backlog`,
`mattpocock-skills`) либо из маркетплейсов formular и mattpocock напрямую, а их отсутствие
останавливает навык с инструкцией установки.

## Подключение

Универсальный путь — корневой `README.md` репозитория tessera: клон и `scripts/bootstrap.sh`
с регистрацией навыков в каталоге харнеса. Установка обновляемым плагином — документ кейсов
`docs/use-cases.md`.
