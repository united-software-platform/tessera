# tessera-plugin

Базовый каркас плагина: навык-заготовка и Python-инструменты. Реальное поведение добавляется
подкомандами в `scripts/tessera_tools.py` и шагами ниже.

## Порядок работы

1. Уточните у пользователя запрошенный результат: каркас пока не содержит предметной логики,
   поэтому решение согласуется до выполнения.
2. Продемонстрируйте работоспособность каркаса вызовом инструмента из корня плагина:

```bash
python3 scripts/tessera_tools.py hello --name "мир"
```

3. Если запрошенное поведение уже реализовано подкомандой — выполните её и сообщите результат.

## Инструменты

| Подкоманда | Назначение |
|------------|------------|
| `hello --name <имя>` | Приветствие-проверка: демонстрация передачи аргументов |
| `info` | Имя и версия плагина из манифеста `.zcode-plugin/plugin.json` |

## Расширение каркаса

- Новая возможность — новая подкоманда `cmd_<имя>` в `scripts/tessera_tools.py` и её регистрация
  в `build_parser`; после добавления описывайте её в таблице «Инструменты».
- Изменение поведения сопровождается повышением `version` в манифесте.
- Ориентир по оформлению документов плагина — правила документации workspace.
