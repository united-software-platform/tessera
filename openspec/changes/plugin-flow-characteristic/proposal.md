# Proposal

## Why

Норма классов ПО не даёт характеристики класса: кроме одной фразы «ПО, поставляющее что-либо
куда-либо», правило отвечает только на вопрос, для кого написано описание. Агент не узнаёт из
него, что плагин — система с двумя потоками: он отдаёт артефакты в другую систему и сам берёт
извне то, без чего не работает и не разрабатывается. В tessera состав плагина и его зависимости
ведутся вручную в трёх описаниях, ничем не обязаны, и сличить их не с чем.

## What Changes

- Норма класса «Плагины» получает характеристику по двум потокам: **поток поставки** — что
  плагин отдаёт в другую систему, это состав плагина; **поток зависимостей** — что плагин берёт
  извне, это зависимости плагина.
- Плагин обязан объявлять состав плагина и зависимости плагина. Зависимость, нужная для работы
  плагина, объявляется в носителях предмета «продукт»; нужная только для работы над плагином —
  в носителях предмета «разработка продукта».
- Потоки разведены: артефакт зависимости не значится в составе плагина, даже когда оказывается
  на машине получателя; артефакт, входящий в оба потока, значится и в составе, и в зависимостях.
- В глоссарий добавляются термины потоков, состава плагина и зависимостей плагина.
- Три описания выравниваются по норме — README плагина, навык-каталог `tessera-plugin` и
  корневой `README.md`: каждое называет состав плагина и его зависимости, README плагина — ещё
  кодом нормы, а лаунчер `backlog` отнесён к потоку зависимостей.
- Версия плагина повышается.
- Не меняются: нормы о предмете описания (PLG-001…PLG-008), скрипты поставки и локальной
  настройки, реестр поставки, проверки репозитория.

## Capabilities

### New Capabilities

- `plugin-flows`: характеристика плагина по двум потокам — поставка и зависимости —
  и обязанность плагина объявлять состав плагина и зависимости плагина.

### Modified Capabilities

Нет: требования `artifact-subject` о предмете описания действуют без изменений.

## Impact

- Правило `plugins/tessera-plugin/rules/software-class-rules.md`: разделы о потоках, новые
  нормы класса, понятия потоков, состава и зависимостей плагина.
- `GLOSSARY.md`: статьи терминов потоков, состава и зависимостей плагина.
- Описания плагина: `plugins/tessera-plugin/README.md`,
  `plugins/tessera-plugin/skills/tessera-plugin/SKILL.md`, `README.md`.
- Точка входа `AGENTS.md`: строка нормы классов ПО в перечне правил.
- Версия плагина: `plugins/tessera-plugin/.zcode-plugin/plugin.json`,
  `plugins/tessera-plugin/.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json`.
- Новая спецификация `plugin-flows`.
- Вне изменения: `scripts/install.sh`, `scripts/setup.sh`, `scripts/check.sh`, реестр поставки
  и спеки `delivery`, `plugin-dependencies`, `local-setup`. Машиночитаемое объявление
  зависимостей и сверка состава и зависимостей с данными скрипта — отдельная задача.
