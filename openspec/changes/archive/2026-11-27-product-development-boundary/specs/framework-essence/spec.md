# Spec Delta

## MODIFIED Requirements

### Requirement: OpenSpec вне поставки

Разработка самого репозитория SHALL вестись через OpenSpec, а харнесы контрибьютора SHALL
готовиться локальной настройкой. Каталог `openspec/`, закрепление CLI и сценарий локальной
настройки SHALL не входить в обещания поставки и лицевые бейджи репозитория. Набор харнесов
при инициализации — выбор контрибьютора.

#### Scenario: Потребитель оценивает поставку

- **WHEN** потребитель читает README
- **THEN** openspec упоминается только как инфраструктура разработки самого tessera
  и не предъявляется как требование или компонент поставки

#### Scenario: Локальная настройка не предъявляется потребителю

- **WHEN** потребитель читает README
- **THEN** локальная настройка не названа способом установки tessera, а порядок работы
  над репозиторием отнесён к `CONTRIBUTING.md`
