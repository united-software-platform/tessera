# Proposal

## Why

Каталог маркетплейса `tessera` несёт записи внешних плагинов `backlog` (репозиторий formular)
и `mattpocock-skills`: установка tessera тянет за собой установку плагинов formular, тогда как
сам formular ссылается на tessera — возникла циклическая зависимость formular ↔ tessera.
Единственный способ разорвать цикл на стороне tessera — перестать поставлять чужие плагины
как собственный состав и оставить их установку разработчику.

## What Changes

- Из каталога маркетплейса `tessera` (`.claude-plugin/marketplace.json`) удаляются записи
  `backlog` и `mattpocock-skills` — каталог несёт только `tessera-plugin`.
  **BREAKING**: команды вида `/plugin install backlog@tessera` перестают работать;
  зависимые плагины устанавливаются из маркетплейсов-источников (formular, mattpocock).
- Зависимости workflow-навыков остаются заявленными: минимальные версии и источники —
  в README плагина; установка каждой — отдельный шаг разработчика при необходимости.
- Проверка зависимостей при запуске сохраняется как единственный механизм закрытия:
  навыки `workflow-fast` и `workflow-grill` первым шагом проверяют доступность навыков
  зависимости; отказ называет установку из маркетплейса-источника напрямую.
- Документы установки переведены на самостоятельную установку зависимостей: корневой
  `README.md`, кейсы 1–2 документа кейсов, README плагина, тексты навыков.
- Добавляются профили установки: кейс «полный набор» в документе кейсов и скрипт
  `scripts/install-plugins.sh` с флагами выбора (`--all`, отдельные зависимости) — «по
  умолчанию всё» остаётся путём копируемых команд и скрипта, без возврата записей в каталог.

## Capabilities

### New Capabilities

- `plugin-dependencies`: опциональная поставка внешних плагинов-зависимостей — каталог
  маркетплейса tessera не несёт чужих плагинов, установка разработчиком из
  маркетплейсов-источников, проверка при запуске навыков с инструкцией установки.

## Impact

- `.claude-plugin/marketplace.json` — состав записей каталога.
- `README.md` (корень) — «Что нужно» и «Ограничения»: установка зависимостей разработчиком.
- `docs/use-cases.md` — кейсы 1–2: установка зависимостей из маркетплейсов-источников.
- `plugins/tessera-plugin/README.md` — раздел «Зависимости»: механизма «записи в том же
  маркетплейсе» больше нет.
- `plugins/tessera-plugin/skills/` — тексты навыков `tessera-plugin`, `workflow-fast`,
  `workflow-grill`: описания зависимостей и инструкции установки в отказах.
- Манифесты плагина `.zcode-plugin/plugin.json` и `.claude-plugin/plugin.json` — повышение
  версии за изменение поведения поставки.
- `scripts/install-plugins.sh` — новый скрипт профилей установки зависимостей.
- `CONTRIBUTING.md` — строка о новом скрипте в «Устройстве репозитория».
- Репозиторий formular — обратная сторона цикла — вне рамок этого изменения.
