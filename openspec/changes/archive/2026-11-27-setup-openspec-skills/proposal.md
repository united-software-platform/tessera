# Proposal

## Why

Установка среды контрибьютора собирается из двух шагов: `mise run setup` ставит навыки плагина,
зависимости и лаунчер, а навыки OpenSpec регистрируются отдельным ручным `openspec init`.
Навыки OpenSpec — часть среды разработки репозитория и должны ставиться той же одной командой
([TSS-021](https://github.com/united-software-platform/tessera/issues/16)).

## What Changes

- Локальная настройка `scripts/setup.sh` после связывания навыков регистрирует навыки OpenSpec:
  `openspec init --tools <отобранные харнесы> --scope project|global --no-animation
  --no-copilot-cloud`. Область `project` настройки соответствует `project` инициализации,
  `user` — `global`.
- CLI остаётся закреплённым в `mise.toml`: шаг выполняется через `mise install` + `mise exec`;
  без mise — openspec из PATH; нет ни того, ни другого — предупреждение, настройка продолжается.
- Существующий `openspec/config.yaml` не перезаписывается: команда идёт без `--language`,
  язык артефактов задаёт конфигурация репозитория. Инициализация идемпотентна.
- `--plugin-only` шаг пропускает: режим без сети и хранилища.
- Проверки: дымовой прогон вариантов пополняется утверждениями о навыках OpenSpec
  и неизменности `openspec/config.yaml`; CI ставит mise, чтобы шаг покрывался прогоном.
- Документы: «Локальная настройка» в `AGENTS.md` и `CONTRIBUTING.md`, статья глоссария
  «Локальная настройка».

## Capabilities

### New Capabilities

_(нет)_

### Modified Capabilities

- `local-setup`: новое требование о регистрации навыков OpenSpec локальной настройкой.

## Impact

- Код: `scripts/setup.sh` (новый шаг и строка отчёта), `scripts/check.sh` (утверждения
  дымового прогона), `.github/workflows/ci.yml` (установка mise).
- Документы: `AGENTS.md`, `CONTRIBUTING.md`, `GLOSSARY.md` — по строке и записи версий.
- Потребители: не затронуты — правка только среды контрибьютора; версия плагина не меняется.
- Задача: закрывает #16.

Вне рамок: закрепление версий навыков OpenSpec и выбор набора харнесов — набор остаётся
выбором контрибьютора (найденные харнесы или перечень `--harness`).
